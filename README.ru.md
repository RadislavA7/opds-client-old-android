# OPDS Client для Onyx Boox (и других старых Android-устройств)

**Язык: [Русский](#) | [English](README.md)**

Лёгкий клиент для просмотра и скачивания книг из **OPDS-каталогов**.
Собран специально под **Android 2.3 (API 9, Gingerbread)** и устройства с E-Ink
(проверено на **Onyx Boox Newton i63**), но работает на любом Android 2.3+.

Размер APK — около **60 КБ**.

## Минимальные требования

- **Android 2.3.1 (API 9)** и выше
- ARM-архитектура (armeabi / armeabi-v7a)
- **~2 МБ** свободного места в памяти устройства
- Доступ к **Wi-Fi / интернету** для работы с каталогами
- Права, которые запрашивает приложение:
  - `INTERNET` — для запросов к OPDS-каталогам
  - `WRITE_EXTERNAL_STORAGE` — для сохранения скачанных книг

> Примечание: приложение работает по протоколу **HTTP**. Старые устройства
> (Android 2.3) не поддерживают современный TLS 1.2 для HTTPS, поэтому OPDS
> каталог должен быть доступен по адресу `http://…`.

> **Рут-доступ НЕ требуется.** Приложение — обычное Android-приложение и
> работает без root. (Root может понадобиться лишь на очень ограниченных
> прошивках, запрещающих установку из сторонних источников — но это не
> связано с самим приложением.)

## Установка

1. Скачайте файл `opds-client.apk`.
2. Разрешите установку из неизвестных источников (Настройки → Безопасность).
3. Откройте APK обычным файловым менеджером и подтвердите установку.
   (Либо установите через adb: `adb install opds-client.apk`.)
4. Запустите приложение и добавьте ваш первый каталог.
   (При первом запуске автоматически добавляется популярный публичный каталог — **Флибуста**;
   он восстанавливается сам, если его удалили, поэтому список никогда не пуст.)

## Возможности

### Работа с каталогами
- **Несколько OPDS-каталогов** одновременно.
- Добавление / редактирование / удаление каталогов.
- Поддержка **HTTP Basic-авторизации** (логин и пароль) — для закрытых каталогов.
- **Поиск по каталогу** через стандарт OPDS OpenSearch (поле + кнопка «Найти»).
- Кнопка **«Обновить»** перезагружает текущий каталог (удобно при нестабильной сети);
  сетевые запросы автоматически повторяются до 3 раз.
- Навигация по подкаталогам прямо из списка.

### Скачивание книг
- Скачивание книг в удобную папку на устройстве.
- **Выбор папки через встроенный проводник** («Обзор…») или вручную.
- **Выбор формата**: если у книги несколько ссылок скачивания (EPUB / MOBI /
  FB2 / PDF и т.д.) — появится список форматов. Если формат один — сразу
  подтверждение. Формат определяется по MIME-типу, который отдаёт каталог.

### Список книг
- Отображение **названия, автора и описания** (аннотации) книги.
- Иконки против автора и описания для наглядности.
- Скачанные книги хранятся в выбранной папке и открываются установленным
  ридером по tap.

### Просмотр книг
- Отдельный экран «Книги» со списком скачанного.
- Автоматический подбор MIME-типа по расширению файла
  (fb2, epub, mobi, azw, pdf, txt, html) и открытие в подходящем ридере.

## Как пользоваться

1. **Добавить каталог** — на главном экране нажмите «Добавить каталог»,
   укажите название и адрес OPDS-каталога. При необходимости — логин и пароль.
2. **Открыть каталог** — нажмите на него в списке.
3. **Поиск** — введите название/автора в верхнем поле и нажмите «Найти».
4. **Скачать книгу** — нажмите на книгу, подтвердите папку (и при нескольких
   форматах — выберите формат).
5. **Папка загрузки** — «Настройки» → «Обзор…», выберите или создайте папку.

## Сборка из исходников

Проект — чистый Android (без библиотек и зависимостей).

Требуется:
- JDK 8
- Android SDK (build-tools, платформа android-9 / android-10)

Сборка вручную:
```
aapt package -f -m -J gen -M AndroidManifest.xml -S res -I android.jar
javac -source 1.6 -target 1.6 -bootclasspath android.jar -classpath gen -d classes src/ru/opds/client/*.java
d8 --min-api 9 --output dexout classes
# упаковать resources + classes.dex в APK, выровнять zipalign, подписать v1 (jarsigner SHA1withRSA)
```

> Для старых устройств обязательна **подпись v1 (JAR)** — Android 2.3 не
> распознаёт подпись v2.

## Файловая структура

| Модуль | Назначение |
|---|---|
| `MainActivity` | Главный экран: список каталогов |
| `SettingsActivity` | Добавление/редактирование каталога (URL, логин, пароль) |
| `CatalogActivity` | Просмотр каталога, поиск, скачивание |
| `FolderPickerActivity` | Встроенный проводник выбора папки |
| `AppSettingsActivity` | Настройки (папка загрузки) |
| `BooksActivity` | Экран скачанных книг |
| `OpdsParser` | Парсинг Atom/OPDS-фида |
| `HttpOp` | HTTP-запросы с Basic-авторизацией |
| `EntryAdapter` | Адаптер списка книг (название, автор, описание) |
| `CatalogStore` / `AppSettingsStore` | Хранение настроек (SharedPreferences) |
